# Expected dynamic export face of sheller.dll - checked in for the
# export_surface gate (tests/export_surface_gate.cmake). Six entries,
# one line per demangled symbol, no more and no less; the gate diffs
# symbol names, it does not count.
#
# Regenerate (never hand-edit) from a windows-release build:
#   dumpbin /exports /nologo build/windows-release/src/shared/Release/sheller.dll
#   take the name column, run each through undname, sort.
# Spellings are MSVC's own (class/struct/enum keywords, __cdecl, __ptr64):
# the Linux list is GCC/c++filt's, and the two are not textually
# comparable: the two demanglers never agree on a spelling (unsigned char vs
# uint8_t, __cdecl, __ptr64, the inline-namespace form of
# std::filesystem::path), so each platform keeps its own list and the pair is
# reconciled by review, with the "exactly six entries" assertion covering the
# count.
